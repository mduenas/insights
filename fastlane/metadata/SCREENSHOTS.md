# Kindling screenshot checklist

Capture real UI (not mockups). Put files in:

- Android: `android/en-US/images/phoneScreenshots/` (1080x2400 preferred)
- iOS: `ios/en-US/screenshots/` (1290x2796 for 6.7")

Suggested order:
1. Home library (Kindling title bar)
2. Search or tag filter active
3. Insight detail with source
4. Personal insights list
5. Add personal insight form
6. Sign-in screen
7. Settings (account + privacy)

Also produce Play feature graphic 1024x500 and 512x512 hi-res icon.
